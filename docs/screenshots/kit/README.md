# Media kit — Marswalk Budget

Screenshots for the slides, the video and the submission page. **Gale Crater first** (the default
site since 2026-11-14 16:11), Jezero second. Taken from the `integrate` branch on 2026-11-14 with
headless Chrome against `npm run serve`.

Sizes: desktop shots are 1600 × 900; crops (`07`–`12`) are 2× pixels; phone shots are 414 × 896 at 2×
(828 × 1792); helmet-view shots are a phone held landscape, 896 × 414 at 2×.

Credits are visible in every shot: Gale imagery is the USGS MRO HiRISE colour mosaic
(NASA/JPL-Caltech/UArizona), Jezero imagery is NASA Mars Trek (MRO HiRISE / CTX), rover traverses
are NASA/JPL MMGIS, stop photos are Curiosity (NASA/JPL-Caltech/MSSS) and Perseverance
(NASA/JPL-Caltech) raw images. Radiation dose is Curiosity RAD, measured at Gale and used as a proxy
at Jezero. Conditions named "demo" or "simulated" and the `data=demo` terrain are synthetic and
labelled so on screen. No NASA logos or mission insignia appear.

## Retaking the shots

Start `npm run serve`, then load each URL in Chrome at the sizes above: `/`,
`/?dust=1&solar=1&kit=1`, `/?data=real`, `/?data=real&dust=1&solar=1&kit=1`, `/?data=demo&kit=1`,
`/?tour=1` (arrow keys step the tour), `tablet.html?data=…`, `hud.html?data=…` and
`hud.html?data=…&vr=1&play=30` (press "Enter helmet view") and `flyover.html?data=…&play=30`.
